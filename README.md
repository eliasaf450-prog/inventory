# 🧥 מערכת ניהול מלאי ביגוד

אפליקציית ווב לניהול מלאי ביגוד לפי חברות ניהול, כולל תהליכי הזמנה, אישורים,
ניהול משימות, מעקב חוסרים והזמנות רכש למחסן הראשי.

נבנתה ב‑**Node.js בלבד ללא תלויות חיצוניות** (שרת HTTP מובנה + `node:sqlite` + `node:crypto`),
כך שהיא רצה בכל מקום עם `node server.js` — בלי `npm install` ובלי גישה לרשת.

## הרצה

```bash
node server.js
# ואז גלישה אל http://localhost:3000
```

דורש Node.js גרסה 22.5 ומעלה (לתמיכה ב‑`node:sqlite`).

בהרצה ראשונה נוצר אוטומטית משתמש מנהל:

| שם משתמש | סיסמה |
|----------|--------|
| `admin`  | `admin123` |

ניתן לשנות באמצעות משתני סביבה: `ADMIN_USER`, `ADMIN_PASSWORD`, `ADMIN_EMAIL`, `PORT`, `DB_PATH`.

## מבנה המערכת

```
server.js        – שרת HTTP, ניתוב REST, לוגיקת תהליכים
src/db.js        – סכמת בסיס הנתונים (SQLite) וזריעה ראשונית
src/auth.js      – גיבוב סיסמאות (scrypt) וטוקני סשן
src/sizes.js     – הגדרות מערכות המידות וסוגי הפריטים
src/xlsx.js      – מנתח קבצי אקסל (.xlsx) ו-CSV ללא תלויות חיצוניות
public/          – ממשק המשתמש (SPA בעברית, RTL, ללא תלויות)
data/            – קובץ בסיס הנתונים (נוצר אוטומטית, לא נשמר ב‑git)
```

## תכולה לפי הדרישות

1. **חברות ניהול** – קטגוריות עליונות לפי חברת ניהול.
2. **סוגי פריטים** – כל חברה מקבלת אוטומטית: חולצות, מכנסיים, נעליים, עניבות,
   ג'קטים, סופטשלים, מעילי דובון. ניתן להוסיף סוגים נוספים.
3. **מערכות מידות**:
   - חולצות – לפי מין; נשים `Y–3XL`, גברים `S–3XL`.
   - מכנסיים – כמו חולצות עם המרה למספרים (היקף מותן).
   - נעליים – לפי יצרן (כולל Blundstone) ומספר; נשים `EU 35–43`, גברים `EU 39–48`.
   - עניבות – ללא מידה.
   - ג'קטים / סופטשלים / מעילים – אותיות או מספרים.
4. **הוספת פריטים** עם בחירת קשת מידות מלאה (אותיות/מספרים/לפי מין/ללא מידה).
5. **כמות במלאי** לכל מוצר.
6. **משתמשים** – כניסה, בחירת פריטים וצפייה בזמינות וכמות.
7. **אישור מנהל** – בקשת משתמש עוברת לאישור המנהל.
8. **משימת לקיחה** – לאחר אישור, המשתמש מאשר לקיחה בפועל; המלאי יורד
   ונרשם חוסר להשלמה.
9. **כמות יעד ומינימום** לכל מוצר.
10. **התראת מינימום** – כשמוצר מגיע למינימום, מוצגת התראה ליצירת הזמנת רכש.
11. **יציאת הזמנה** – המנהל מאשר ביצוע ויציאה למחסן; נרשם מועד ומתחילה ספירת זמן.
12. **התראת מעקב** – תדירות התראה (שבוע / שבועיים / חודש) לבדיקת סטטוס הזמנה
    שטרם הגיעה.
13. **קבלת הזמנה** – הזנת מספר PO וכמויות שהתקבלו; המערכת מזהה אם התקבל הכל
    או מה חסר.
14. **התחברות** בשם משתמש וסיסמה.
15. **הרשמה** באמצעות אימייל (ממתינה לאישור מנהל).
16. **מנהל מספק סיסמה** – יצירת משתמשים, אישור הרשמות ואיפוס סיסמאות.

### אתרים ועובדים + ייבוא מאקסל

- ניהול **אתרים** (סניפים/מתקנים) ו**עובדים** המשויכים לאתר.
- **טעינה מקובץ אקסל (.xlsx) או CSV** במסך "אתרים ועובדים":
  1. בחירת קובץ → תצוגה מקדימה של השורות.
  2. סימון אם השורה הראשונה היא כותרת.
  3. מיפוי עמודות (שם / קוד / מספר עובד / אתר) — עובד עם כל מבנה קובץ.
  4. ייבוא; בייבוא עובדים ניתן ליצור אוטומטית אתרים חדשים לפי שם האתר.
- בעת יצירת בקשת ביגוד ניתן לשייך אותה (אופציונלי) לאתר ולעובד, והמידע מוצג
  למנהל באישור ההזמנה.

ניתוח ה‑xlsx מתבצע בקוד פנימי (פענוח ZIP בעזרת `zlib` המובנה) — ללא ספריות חיצוניות.

## תהליך עבודה לדוגמה

1. התחברות כמנהל → **ניהול מלאי** → הוספת חברת ניהול → הוספת מוצרים עם כמות,
   יעד ומינימום.
2. **ניהול משתמשים** → אישור הרשמות או יצירת משתמשים.
3. משתמש מתחבר → **בקשת ביגוד** → בוחר חברה, סוג, מידה וכמות → שולח לאישור.
4. מנהל → **אישור הזמנות** → מאשר.
5. משתמש → מאשר **לקיחת ביגוד** → המלאי יורד, נרשם חוסר.
6. מנהל → **הזמנות רכש** → יוצר הזמנה לפי חוסרים → אישור → יציאה למחסן →
   קבלה עם מספר PO.
